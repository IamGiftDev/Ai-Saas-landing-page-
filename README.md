## 🧭 Customization Guide

| Task | File / Area | Tip |
|------|--------------|-----|
| ✍️ Edit text & buttons | `index.html` | Modify hero headline, CTA buttons |
| 🎨 Change colors | Tailwind classes | Replace gradient or accent shades |
| 🖼️ Swap images | `assets/images` | Use your own avatars or icons |
| ✨ Adjust animations | `data-aos` attributes | Examples: `fade-up`, `zoom-in`, `flip-right` |
